# live

自建直播工程仓库，按**研究方向**组织。

## 研究方向

| 方向 | 路径 | 协议 | 状态 |
|------|------|------|------|
| **前沿研究 / 演进** | [前沿研究-演进/MoQ](./前沿研究-演进/MoQ) | **MoQ**（Media over QUIC） | IETF 草案；一套协议覆盖推流+分发；大规模生产多在 **2027+** |
| **当下最先进且可落地** | [当下最先进且可落地/WHIP-WHEP](./当下最先进且可落地/WHIP-WHEP) | **WHIP + WHEP**（WebRTC） | WHIP = **RFC 9725**；WHEP 草案但已广泛试用；**亚秒级**，可落地 |

## 怎么选

- **要做自家 Android 直播、马上联调** → 进入 [`当下最先进且可落地/WHIP-WHEP`](./当下最先进且可落地/WHIP-WHEP)
- **跟踪下一代协议** → 进入 [`前沿研究-演进/MoQ`](./前沿研究-演进/MoQ)

## 协议速览

| | MoQ | WHIP + WHEP |
|--|-----|-------------|
| 推流+分发 | 目标上统一 | 推流 WHIP / 拉流 WHEP，源站可再转 HLS |
| 延迟 | 目标亚秒 + 可扩规模 | 亚秒级互动观看 |
| 标准 | IETF 草案演进中 | WHIP 已 RFC；WHEP 草案常用 |
| 本仓库 | 预研占位 | **主工程（SDK + 服务器）** |
