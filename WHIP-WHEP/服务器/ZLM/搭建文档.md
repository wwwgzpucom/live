# ZLM（ZLMediaKit）搭建文档

> 官方仓库：[ZLMediaKit/ZLMediaKit](https://github.com/ZLMediaKit/ZLMediaKit)  
> 文档：[指南](https://docs.zlmediakit.com/zh/guide/) · [WebRTC 信令](https://docs.zlmediakit.com/zh/guide/protocol/webrtc/webrtc_signaling_interaction_format.html)

ZLMediaKit（简称 ZLM）是高性能 C++ 流媒体服务器，支持 RTMP/RTSP/HLS/HTTP-FLV/WebRTC，并支持标准 **WHIP / WHEP**。

---

## 1. 环境要求

- Docker（推荐）或源码编译
- 常用端口：

  | 端口 | 协议 | 用途 |
  |------|------|------|
  | 1935 | TCP | RTMP |
  | 80（容器内）/ 映射 8080 | TCP | HTTP API、HLS、WHIP/WHEP 信令 |
  | 443 | TCP | HTTPS |
  | 554 | TCP | RTSP |
  | 8000 | UDP | WebRTC ICE/媒体（关键） |
  | 9000 | UDP | 其它 RTC 相关（按镜像说明） |
  | 10000 | TCP/UDP | 按镜像说明 |

---

## 2. Docker 一键启动（推荐）

```bash
docker run -d --name zlm --restart unless-stopped \
  -p 1935:1935 \
  -p 8080:80 \
  -p 8443:443 \
  -p 8554:554 \
  -p 10000:10000 \
  -p 10000:10000/udp \
  -p 8000:8000/udp \
  -p 9000:9000/udp \
  zlmediakit/zlmediakit:master
```

或使用本目录 `docker-compose.yml`：

```bash
cd 服务器/ZLM
docker compose up -d
```

查看日志：

```bash
docker logs -f zlm
```

## 3. WHIP / WHEP 地址

假设宿主机 IP 为 `192.168.1.10`，HTTP 映射到 `8080`，流为 `live/demo`：

| 用途 | URL |
|------|-----|
| WHIP 推流 | `http://192.168.1.10:8080/index/api/whip?app=live&stream=demo` |
| WHEP 拉流 | `http://192.168.1.10:8080/index/api/whep?app=live&stream=demo` |

请求方式：`POST`，`Content-Type: application/sdp`，Body 为 SDP Offer（与本仓库 Android SDK 一致）。

也可使用 ZLM 私有信令（非 WHIP）：

```text
POST /index/api/webrtc?app=live&stream=demo&type=push
POST /index/api/webrtc?app=live&stream=demo&type=play
```

**自建直播建议优先走 WHIP/WHEP**，与 SDK 统一。

其它播放示例：

| 协议 | URL |
|------|-----|
| HTTP-FLV | `http://192.168.1.10:8080/live/demo.live.flv` |
| HLS | `http://192.168.1.10:8080/live/demo/hls.m3u8` |
| RTMP | `rtmp://192.168.1.10/live/demo` |

（具体 HLS/FLV 路径以当前 ZLM 版本与 `config.ini` 为准，可用管理接口查流。）

## 5. 关键配置：对外 ICE 地址

若出现「信令成功但播放超时 / 无画面」，通常是 WebRTC UDP（默认 **8000**）不通，或服务器对外宣告的 IP 不对。

需要挂载并修改 `config.ini` 中 `[rtc]` 相关项（字段名随版本可能略有差异），保证：

1. 防火墙放行 `8000/udp`（及文档要求的其它端口）
2. 配置对外可见的 IP（`externIP` / `candidate` 类配置，以当前版本文档为准）

挂载配置示例：

```bash
docker run -d --name zlm \
  -v /path/to/config.ini:/opt/media/conf/config.ini \
  -p 1935:1935 -p 8080:80 -p 8000:8000/udp \
  zlmediakit/zlmediakit:master
```

（容器内配置路径以镜像说明为准，可用 `docker exec -it zlm sh` 查看。）

## 6. 常见问题

1. **只通信令不通媒体**：检查 8000/udp 与公网/NAT 映射。  
2. **secret 鉴权**：默认 `config.ini` 可能开启 API secret，调用管理接口时需带 `secret` 参数。  
3. **HTTPS**：公网浏览器场景建议上 443 与证书。
