# OME（OvenMediaEngine）搭建文档

> 官方仓库：[OvenMediaLabs/OvenMediaEngine](https://github.com/OvenMediaLabs/OvenMediaEngine)  
> 文档：[Quick Start](https://docs.ovenmediaengine.com/) · [Docker](https://ovenmedialabs.com/docs/ome/getting-started/getting-started-with-docker) · [WHIP](https://ovenmedialabs.com/docs/ome/live-source/webrtc)

OvenMediaEngine（OME）面向**超低延迟**直播，支持 RTMP / SRT / **WHIP** 推流，以及 WebRTC、LL-HLS 播放。配套可用 OvenPlayer / OvenLiveKit。

> 说明：OME 推流侧 WHIP 很成熟；播放侧官方主推 WebRTC 信令（WebSocket）与 LL-HLS。若 Android SDK 固定走 WHEP，需确认当前 OME 版本是否已提供 WHEP，或播放改用 LL-HLS / 官方信令。联调 WHIP 推流可优先用 OME。

---

## 1. 环境要求

- Docker（推荐）
- `OME_HOST_IP`：**播放器/推流端可达的主机 IP**（必填）
- 常用端口：

  | 端口 | 协议 | 用途 |
  |------|------|------|
  | 1935 | TCP | RTMP |
  | 3333 | TCP | WebRTC / WHIP 信令 |
  | 3334 | TCP | TLS 信令（可选） |
  | 3478 | TCP | TURN / TcpRelay |
  | 9000 | TCP | 部分服务 |
  | 9999 | UDP | SRT |
  | 10000–10009 | UDP | WebRTC ICE 媒体 |

---

## 2. Docker 一键启动（推荐）

```bash
export OME_HOST_IP=YOUR_LAN_IP

docker run -d --name ome --restart unless-stopped \
  -e OME_HOST_IP=$OME_HOST_IP \
  -p 1935:1935 \
  -p 9999:9999/udp \
  -p 9000:9000 \
  -p 3333:3333 \
  -p 3478:3478 \
  -p 10000-10009:10000-10009/udp \
  ovenmedialabs/ovenmediaengine:latest
```

或使用本目录 `docker-compose.yml`：

```bash
cd 服务器/OME
export OME_HOST_IP=YOUR_LAN_IP
docker compose up -d
```

查看日志：

```bash
docker logs -f ome
```

生产环境建议 pin 具体版本标签（如 `v0.20.5`），避免 `latest` 漂移。

## 3. 推流 / 播放地址

假设 IP 为 `192.168.1.10`，默认应用名 `app`、流名 `stream`：

| 用途 | URL |
|------|-----|
| WHIP 推流 | `http://192.168.1.10:3333/app/stream?direction=whip` |
| RTMP 推流 | 服务器 `rtmp://192.168.1.10:1935/app`，流密钥 `stream` |
| SRT 推流 | `srt://192.168.1.10:9999?streamid=srt%3A%2F%2F192.168.1.10%3A9999%2Fapp%2Fstream` |
| WebRTC 播放（官方信令） | `ws://192.168.1.10:3333/app/stream` |
| LL-HLS 播放 | `http://192.168.1.10:3333/app/stream/llhls.m3u8` |

可用官方 OvenPlayer Demo 快速验证播放：

```bash
docker run -d -p 8090:80 airensoft/ovenplayerdemo:latest
# 浏览器打开 http://本机:8090 ，填入上面的 WebRTC / LLHLS 地址
```

## 4. 对接 Android SDK

### WHIP 推流

```text
WHIP: http://192.168.1.10:3333/app/stream?direction=whip
```

### 拉流

- 若坚持 WHEP：先确认当前 OME 版本能力，或在源站前加支持 WHEP 的网关。  
- 更稳妥：观看端用 **LL-HLS**（ExoPlayer）或对接 OME WebSocket 信令。  
- 本仓库第一版 SDK 以 WHEP 为主时，**服务端联调优先建议 SRS / ZLM**；OME 适合作为 WHIP 推流与超低延迟播放实验。

## 5. OBS 推流建议（低延迟）

| 项 | 建议值 |
|----|--------|
| Keyframe Interval | 1s（不要设 0） |
| CPU Preset | ultrafast |
| Profile | baseline |
| Tune | zerolatency |

---

## 6. 常见问题

1. **OME_HOST_IP 未设或设错**：ICE 候选错误，表现为连上无画面。  
2. **UDP 端口范围未映射**：`10000-10009/udp` 必须开放。  
3. **AGPL 协议**：商用闭源分发需评估许可证；仅内部自建一般可接受，请法务确认。
