# SRS 搭建文档

> 官方仓库：[ossrs/srs](https://github.com/ossrs/srs)  
> 文档：[WebRTC / WHIP / WHEP](https://ossrs.net/lts/en-us/docs/v6/doc/webrtc)

SRS（Simple Realtime Server）适合国内自建直播，原生支持 **WHIP 推流** 与 **WHEP 拉流**，可与本仓库 `SDK/` 中的 Android 客户端直接联调。

---

## 1. 环境要求

- Docker（推荐）或 Linux 源码编译
- 开放端口（至少）：
  | 端口 | 协议 | 用途 |
  |------|------|------|
  | 1935 | TCP | RTMP |
  | 1985 | TCP | HTTP API / WHIP / WHEP 信令 |
  | 8080 | TCP | HTTP-FLV / HLS / 播放页 |
  | 8000 | UDP | WebRTC 媒体 |

---

## 2. Docker 一键启动（推荐）

将下面的 `YOUR_LAN_IP` 换成**手机/客户端能访问到的服务器 IP**（不要用 `127.0.0.1`，真机联调会失败）。

```bash
export CANDIDATE=YOUR_LAN_IP

docker run -d --name srs --restart unless-stopped \
  -e CANDIDATE=$CANDIDATE \
  -p 1935:1935 \
  -p 1985:1985 \
  -p 8080:8080 \
  -p 8000:8000/udp \
  ossrs/srs:5 \
  objs/srs -c conf/rtc.conf
```

也可使用本目录 `docker-compose.yml`：

```bash
cd 服务器/SRS
export CANDIDATE=YOUR_LAN_IP
docker compose up -d
```

查看日志：

```bash
docker logs -f srs
```

## 3. 地址一览

假设服务器 IP 为 `192.168.1.10`，流名为 `demo`：

| 用途 | URL |
|------|-----|
| WHIP 推流 | `http://192.168.1.10:1985/rtc/v1/whip/?app=live&stream=demo` |
| WHEP 拉流 | `http://192.168.1.10:1985/rtc/v1/whep/?app=live&stream=demo` |
| HTTP-FLV | `http://192.168.1.10:8080/live/demo.flv` |
| HLS | `http://192.168.1.10:8080/live/demo.m3u8` |
| RTMP | `rtmp://192.168.1.10/live/demo` |

浏览器自带播放页（SRS 容器内）：

- WHEP：`http://192.168.1.10:8080/players/whep.html`

---

## 4. 对接 Android SDK

在 Demo 首页填写：

```text
WHIP: http://192.168.1.10:1985/rtc/v1/whip/?app=live&stream=demo
WHEP: http://192.168.1.10:1985/rtc/v1/whep/?app=live&stream=demo
```

模拟器访问本机可用 `10.0.2.2` 代替局域网 IP；真机必须用电脑局域网 IP，并保证同一网段。

## 5. 常见问题

### 5.1 信令成功但无画面

多半是 **CANDIDATE 配错** 或 **8000/udp 未放行**。  
`CANDIDATE` 必须是客户端可达的公网/局域网 IP。

### 5.2 跨网 / HTTPS

浏览器跨设备推流有时要求 HTTPS；Android App 走 HTTP 在局域网通常可用。  
公网部署请配域名证书，或用 Nginx 反代 1985/8080。

### 5.3 RTMP 与 WebRTC 互转

若需要 OBS 推 RTMP、手机看 WebRTC，可改用：

```bash
objs/srs -c conf/rtmp2rtc.conf
```
