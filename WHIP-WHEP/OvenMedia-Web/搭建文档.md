# OvenMedia 官方 Web 三件套 · 搭建文档

目标：在浏览器侧跑通一条完整链路——**OvenLiveKit 推流 → OvenMediaEngine → OvenPlayer 播放**。  
本页**只写 Web 端**，不涉及 Android。

---

## 0. 架构速览

| 层级 | 组件 | 协议 |
|------|------|------|
| 推流 | OvenLiveKit-Web | WHIP（HTTP + WebRTC）或 OME 自有 WebRTC 信令 |
| 源站 | OvenMediaEngine | 收 WHIP/RTMP/SRT，出 WebRTC / LL-HLS / HLS |
| 播放 | OvenPlayer | WebRTC（OME 信令）/ LLHLS / HLS / DASH |

典型地址（主机 IP 记为 `HOST`，默认应用 `app`、流名 `stream`）：

| 用途 | URL |
|------|-----|
| WHIP 推流 | `http://HOST:3333/app/stream?direction=whip` |
| WebRTC 播放 | `ws://HOST:3333/app/stream` |
| LL-HLS 播放 | `http://HOST:3333/app/stream/llhls.m3u8` |

## 1. 启动 OvenMediaEngine（服务端）

### 1.1 环境

- 已安装 Docker
- `OME_HOST_IP` = **浏览器能访问到的机器 IP**（局域网或公网；不要用仅本机可达的错误地址）

### 1.2 Docker 启动

```bash
export OME_HOST_IP=YOUR_LAN_OR_PUBLIC_IP

docker run -d --name ome --restart unless-stopped \
  -e OME_HOST_IP=$OME_HOST_IP \
  -p 1935:1935 \
  -p 9999:9999/udp \
  -p 9000:9000 \
  -p 3333:3333 \
  -p 3478:3478 \
  -p 10000-10009:10000-10009/udp \
  ovenmedialabs/ovenmediaengine:latest
```

也可用本仓库已有 compose：

```bash
cd WHIP-WHEP/服务器/OME
export OME_HOST_IP=YOUR_LAN_OR_PUBLIC_IP
docker compose up -d
```

查看日志：

```bash
docker logs -f ome
```

### 1.3 端口（Web 联调至少要通）

| 端口 | 用途 |
|------|------|
| 3333/TCP | WHIP 信令、WebRTC 播放信令 |
| 3478/TCP | 内置 TURN / TcpRelay（弱网/TCP 场景） |
| 10000–10009/UDP | WebRTC 媒体 |
| 1935/TCP | 可选：OBS RTMP 推流 |

生产建议 pin 版本标签（如 `v0.20.5`），避免 `latest` 漂移。服务端许可为 **AGPL-3.0**。

## 2. 推流：OvenLiveKit-Web

### 2.1 是什么

[OvenLiveKit-Web](https://github.com/OvenMediaLabs/OvenLiveKit-Web) 是官方 **JavaScript 直播编码器**，面向浏览器，封装摄像头/麦克风采集，并向 OME 做 WebRTC / WHIP 推流。许可 **MIT**。

### 2.2 快速验证（不必先写业务页）

可用官方演示或 OvenSpace；自建时典型 WHIP 推流地址：

```text
http://HOST:3333/app/stream?direction=whip
```

浏览器需授予摄像头、麦克风权限；跨机访问时注意 HTTP/HTTPS 与防火墙。

### 2.3 接入注意

- WHIP：HTTP(S) + `?direction=whip`
- 也可使用 OME 自有推流信令：`ws://HOST:3333/app/stream?direction=send`（与播放信令区分靠 query）
- 弱网可关注文档中的 `transport=tcp` / TURN 相关参数

文档入口：

- https://github.com/OvenMediaLabs/OvenLiveKit-Web  
- https://ovenmedialabs.com/docs/ome/live-source/webrtc

## 3. 播放：OvenPlayer

### 3.1 是什么

[OvenPlayer](https://github.com/OvenMediaLabs/OvenPlayer) 是官方 **HTML5 播放器**，针对 OME 优化，支持：

- 亚秒：WebRTC（OME 信令）
- 低延迟可扩规模：LLHLS
- 兼容：HLS、DASH 等  

许可 **MIT**。

### 3.2 最快验证：官方 Player Demo 容器

```bash
docker run -d --name ovenplayer-demo -p 8090:80 airensoft/ovenplayerdemo:latest
```

浏览器打开：`http://HOST:8090/`

添加播放源示例：

| 类型 | Playback URL |
|------|----------------|
| WebRTC | `ws://HOST:3333/app/stream` |
| LLHLS | `http://HOST:3333/app/stream/llhls.m3u8` |

先完成第三节推流，再点播放。

### 3.3 业务页嵌入（概念）

```html
<script src="https://cdn.jsdelivr.net/npm/ovenplayer/dist/ovenplayer.js"></script>
<div id="player"></div>
<script>
  const player = OvenPlayer.create('player', {
    sources: [{
      type: 'webrtc',
      file: 'ws://HOST:3333/app/stream'
    }]
  });
</script>
```

LLHLS 示例将 `type` / `file` 换成 LLHLS 地址即可。细节以 [OvenPlayer 文档](https://ovenmedialabs.com/docs/ovenplayer) 为准。

npm：

```bash
npm install ovenplayer
```

## 4. 推荐联调顺序（Web 全链路）

1. 起 **OME**，确认 `OME_HOST_IP` 正确、UDP 媒体口已放行  
2. 打开本目录 **[`web/`](./web/)**：改 `config.js` → `npx serve` → 浏览器测主播/观众  
3. 或单独用 OvenLiveKit / OvenPlayer Demo 验证  
4. 安卓壳 WebView 打开同一 `web/` 入口（始终在 App 内）

可选：参考 [OvenSpace](https://github.com/OvenMediaLabs/OvenSpace) 看官方产品拼法。

## 5. 常见问题

| 现象 | 排查 |
|------|------|
| 信令通、无画面 | `OME_HOST_IP` 是否为观众/主播可达 IP；`10000-10009/udp` 是否放行 |
| 仅本机可播、手机不行 | 不要用 `127.0.0.1`；改局域网/公网 IP，并检查防火墙 |
| 浏览器限制采集 | 非安全上下文（非 localhost 的 HTTP）可能限制 getUserMedia；上 HTTPS 或本机调试 |
| 人一多 WebRTC 吃力 | 观看改 LL-HLS；互动位保留 WebRTC |
